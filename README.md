Showcase using aztec with hardhat. This repo is meant to be used specifically with Aztec version `3.0.0-devnet.5`, as it grabs the Aztec l1-contracts from the corresponding tagged release (see [here]([url](https://github.com/critesjosh/hardhat-aztec-example/blob/79933eed7c234e8004a64b5ef77268bf5f70571d/package.json#L18))).

All you need is the postinstall script and dependencies in package.json

Then you should be able to `npm install && npx hardhat build`
